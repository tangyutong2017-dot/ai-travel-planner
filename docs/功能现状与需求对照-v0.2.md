## 0. 一句话结论（写于 2026-08-11，现已不成立）

**骨架和外壳已经完整，大脑被摘掉了。**

创建 → 生成 → 编辑 → 输出这条主链路端到端跑得通，数据真实落 Postgres，
但"生成"环节目前产出的是占位行程——AI 生成、天气、路线三块能力尚未接入。

> 后续进展：Generation Agent 已接入（DeepSeek v4 Flash + Tavily 联网 + 高德核实），
> 天气按真实日期匹配，通勤走高德实测路线，地图已渲染。

## 5. 立项建议的优先级

按"作品集能不能拿得出手"排序，而非按 PRD 原序：

1. **Generation Agent 重写** — 项目的核心价值主张，也是 P1 全部缺口的前置
2. **接 `driving_route` + `weather_for_city`** — 代码已写好，接上就能让地图和天气卡片活过来，性价比最高
3. **PDF 导出**（补齐 P0）— `window.print()` + 打印样式即可交差
4. **AI 调整输入框** — 依赖 Editing Agent，与第 1 项一起规划

## 6. 如何复现本文档的测试

```bash
# 1. 起后端（需 Postgres 在跑）
cd backend && .venv/bin/uvicorn app.main:app --reload --port 8000

# 2. 跑后端全量冒烟测试
python3 backend/tests/smoke_test.py

# 3. 起前端
cd web && npm run dev
```

- 应用：http://localhost:5173
- API 文档：http://localhost:8000/docs

**已知不足**：`smoke_test.py` 是脚本形态、依赖真实运行的服务和数据库。
后续应改造为 pytest + FastAPI `TestClient`，并用独立测试库，才能进 CI。
